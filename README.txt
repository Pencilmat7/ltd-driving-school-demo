LTD DRIVING SCHOOL — BOOKING SYSTEM DEMO

What this is:
A local working prototype with a customer booking page and a private admin dashboard.

Run it:
1. Install Node.js (LTS) from https://nodejs.org/
2. Open a terminal in this folder.
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000
6. Admin dashboard: http://localhost:3000/admin

Demo admin login:
Username: ltdadmin
Password: ChangeMe123!

IMPORTANT BEFORE PUBLIC DEPLOYMENT:
- Change ADMIN_PASSWORD and SESSION_SECRET using environment variables.
- Use HTTPS.
- Use a real database/service instead of the demo JSON file for production.
- Add proper email/SMS confirmations and business rules.
- Confirm LTD's actual services, hours, prices, cancellation rules, and scheduling workflow before launch.
- Get permission from LTD for any photos/content they want retained on the public site.
